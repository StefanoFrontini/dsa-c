### 🔍 Verifica dell'Equazione e dei Tipi

L'equazione algebrica formale del Dove è:

$$D x y z w = x y (z w)$$

Ripercorrendo la tua implementazione:

1. `x` è una funzione curificata a due argomenti: `(arg: R) => (arg: U) => V`.
2. `y` è il primo dato per $x$, di tipo `R`. Quindi `x(y)` restituisce una funzione `(arg: U) => V`.
3. `z` è una funzione di trasformazione `(arg: T) => U`.
4. `w` è l'argomento iniziale di tipo `T`.
5. `z(w)` produce un valore di tipo `U`.
6. Passando `z(w)` a `x(y)`, otteniamo il risultato finale $V$.

### 🎨 Esempio nel Picture Language

Il Dove ($D$) è utilissimo quando vuoi combinare due pittori (con una funzione binaria come `beside` o `below`), ma vuoi applicare una trasformazione preliminare (come `rotate90` o `flip_vert`) **solo al secondo pittore** prima della combinazione.

`​`​`typescript
const D =
  <R, U, V>(x: (arg: R) => (arg: U) => V) =>
  (y: R) =>
  <T>(z: (arg: T) => U) =>
  (w: T): V =>
    x(y)(z(w));

// Impostiamo:
// x = beside   (unisce due pittori affiancati)
// y = wave     (pittore di sinistra, non modificato)
// z = rotate90 (trasformazione da applicare al secondo)
// w = rooster  (pittore di destra)

const resultPainter = D(beside)(wavePainter)(rotate90)(roosterPainter);
`​`​`
