### Versione Type-Safe (Senza `any`)

In TypeScript puoi tipizzare il Mockingbird in modo rigoroso definendo un tipo di funzione ricorsivo:

`​`​`typescript
// Un tipo di funzione che accetta come argomento se stessa
type SelfApplicable<R = unknown> = (x: SelfApplicable<R>) => R;

// Il Mockingbird fortemente tipizzato
const M = <R>(x: SelfApplicable<R>): R => x(x);
`​`​`

### Come funziona l'inferenza di tipo:

1. `SelfApplicable<R>` descrive una funzione con firma `(arg: SelfApplicable<R>) => R`.
2. Passando `x` a se stessa (`x(x)`), il parametro `x` soddisfa esattamente il tipo del suo stesso argomento.
3. Il valore di ritorno `R` viene inferito automaticamente in base a cosa restituisce la funzione passata.

---

### Esempio Pratico

`​`​`typescript
// Una funzione compatibile con M: accetta se stessa e restituisce una stringa
const hello: SelfApplicable<string> = (self) => "Ciao da Mockingbird!";

const result = M(hello); // Tipo inferito: string
console.log(result);     // "Ciao da Mockingbird!"
`​`​`

### Un'avvertenza sul Mockingbird

Mentre combinatori come $B$ (Bluebird) o $C$ (Cardinal) creano trasformazioni e pipeline lineari, il Mockingbird $M$ è il mattoncino fondamentale per costruire la **ricorsione pura** (e il celebre combinatore Y).

Fai attenzione se provi ad applicare il Mockingbird a se stesso:

$$M(M) \implies M M \implies M M \dots$$

In JavaScript/TypeScript, eseguire `M(M as any)` produce il combinatore $\Omega$ (Omega), scatenando un loop infinito che causa un'eccezione di *Maximum call stack size exceeded*.
