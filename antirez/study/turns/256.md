Certamente! I Web Components sono solo un "vestito formale" messo a disposizione dal browser per impacchettare la grafica, ma l'Actor Model funzionale vive di logica pura. Puoi applicarlo a qualsiasi elemento HTML standard (`<div>`, `<button>`, `<span>`) già esistente nella pagina, usando semplicemente le **chiusure (closures)** per intrappolare i riferimenti ai nodi del DOM.

In questo approccio, eliminiamo del tutto le classi e i tag personalizzati. L'attore diventa una funzione che, oltre a gestire lo stato, ha una presa diretta su un elemento del DOM tramite il suo ID o selettore.

---

## L'Architettura con Chiusure e Selettori DOM

Invece di chiedere al browser di creare un nuovo ciclo di vita con i Web Components, usiamo una funzione di inizializzazione che mappa l'attore direttamente su un elemento HTML normale.

Ecco come si struttura il codice in JavaScript Vanilla purissimo:

### 1. La Fabbrica di Attori UI Generica
Questa funzione prende un elemento del DOM, uno stato iniziale, una funzione di comportamento e l'Attore Core a cui abbonarsi. Isola tutto dentro la closure.

`​`​`javascript
function legaAttoreAlDom(idElemento, statoIniziale, funzioneTransizione, attoreCore) {
    // Il nodo del DOM viene catturato qui e protetto dalla closure
    const elementoDom = document.getElementById(idElemento);
    if (!elementoDom) {
        console.error(`Impossibile trovare l'elemento con ID: ${idElemento}`);
        return;
    }

    let statoLocale = statoIniziale;
    const mailbox = [];

    function svuotaMailbox() {
        if (mailbox.length === 0) return;
        const evento = mailbox.shift();

        // Passiamo l'elemento DOM alla funzione di transizione per manipolarlo
        statoLocale = funzioneTransizione(elementoDom, statoLocale, evento);

        if (mailbox.length > 0) {
            queueMicrotask(svuotaMailbox);
        }
    }

    function send(evento) {
        mailbox.push(evento);
        if (mailbox.length === 1) {
            queueMicrotask(svuotaMailbox);
        }
    }

    // Ci abboniamo direttamente all'Attore Core (il cervello della radio)
    const unsubscribe = attoreCore.subscribe(() => {
        const snapshotCore = attoreCore.getSnapshot();
        send({ type: 'STATO_CORE_VARIATO', payload: snapshotCore });
    });

    // Restituiamo la funzione di invio e quella di pulizia
    return { send, unsubscribe };
}
`​`​`

## 🎭 Definizione dei Comportamenti Puri della UI

Ora i comportamenti della UI diventano funzioni che ricevono il nodo HTML come primo argomento, modificando solo ed esclusivamente quel pezzetto di schermo.

### 1. Il Comportamento del Testo di Stato (`#status-text`)
`​`​`javascript
function comportamentoTesto(elemento, statoLocale, evento) {
    if (evento.type === 'STATO_CORE_VARIATO') {
        // Colpiamo chirurgicamente il DOM senza intermediari
        elemento.textContent = `Stato Radio: ${evento.payload}`;
        return { testo: evento.payload };
    }
    return statoLocale;
}
`​`​`

### 2. Il Comportamento del Pulsante (`#play-btn`)
`​`​`javascript
function comportamentoPulsante(elemento, statoLocale, evento) {
    if (evento.type === 'STATO_CORE_VARIATO') {
        const isPlaying = evento.payload === 'PLAYING';
        elemento.textContent = isPlaying ? 'Ferma Radio' : 'Ascolta Live';
        elemento.className = isPlaying ? 'btn-danger' : 'btn-success';
        return { modalita: evento.payload };
    }
    return statoLocale;
}
`​`​`

## ⚙️ Messa in Moto nel file HTML

Nel tuo file `index.html` ti basta scrivere del codice HTML vanilla normalissimo, senza script complessi o framework:

`​`​`html
<div class="player-card">
    <span id="status-text">Inizializzazione...</span>
    <button id="play-btn" class="btn-play">Ascolta Live</button>
</div>
`​`​`

Nel tuo file `app.js`, non appena la pagina ha finito di caricarsi, colleghi i fili logici agli elementi fisici:

`​`​`javascript
document.addEventListener('DOMContentLoaded', () => {
    
    // 1. Colleghiamo l'attore del testo di stato
    legaAttoreAlDom('status-text', { testo: 'STOPPED' }, comportamentoTesto, attorePlayer);

    // 2. Colleghiamo l'attore del pulsante
    const pulsanteAttore = legaAttoreAlDom('play-btn', { modalita: 'STOPPED' }, comportamentoPulsante, attorePlayer);

    // 3. Gestiamo l'evento di input (il clic) inviando il messaggio all'Attore Core
    document.getElementById('play-btn').addEventListener('click', () => {
        const statoAttuale = attorePlayer.getSnapshot();
        const comando = statoAttuale === 'PLAYING' ? 'STOP' : 'PLAY';
        attorePlayer.send({ type: comando });
    });
});

## 🚀 I Vantaggi di eliminare anche i Web Components

* **Compatibilità Totale:** Questo codice gira su qualsiasi browser esistente, anche il più vecchio, perché non richiede il supporto alle specifiche moderne dei Custom Elements o dello Shadow DOM. Usa solo funzioni e manipolazione standard.
* **Integrazione con HTML Esistente:** Se devi applicare l'Actor Model a una pagina web già scritta da altri (o generata lato server da PHP, Node.js o Python), non devi stravolgere l'HTML trasformandolo in componenti. Ti basta agganciare i tuoi attori funzionali agli ID degli elementi già presenti sul foglio.
* **Leggerezza Assoluta:** Non essendoci l'ereditarietà delle classi dei Web Components (`extends HTMLElement`), il consumo di memoria si riduce ulteriormente. Un attore è letteralmente una manciata di byte intrappolata in una closure.
