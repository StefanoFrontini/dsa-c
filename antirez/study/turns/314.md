Il caso d'uso perfetto per il **Robin ($R x y z = y z x$)** nel *Picture Language* si presenta quando **hai già un pittore $x$ e vuoi fissarlo come secondo argomento (a destra o in alto) di una funzione spaziale $y$, lasciando libero il primo argomento $z$**.

---

### Il Problema Geometria: Invertire l'ordine degli argomenti

La funzione `beside` accetta i pittori nell'ordine `(sinistra)(destra)`:

`​`​`typescript
// beside: (left: Painter) => (right: Painter) => Painter
`​`​`

Immagina di voler creare un componente grafico riutilizzabile in cui **`wavePainter` deve stare sempre a DESTRA**, ma non sai ancora quale pittore gli verrà affiancato a SINISTRA.

Senza combinatori dovresti scrivere una funzione freccia manuale:
`​`​`typescript
const attachToRightOf = (leftPainter: Painter) => beside(leftPainter)(wavePainter);
`​`​`

---

### La Soluzione con il Robin ($R$)

Sfruttando l'equazione $R x y z = y z x$, impostiamo:
* **$x = \text{wavePainter}$** (il pittore fisso che vogliamo a destra)
* **$y = \text{beside}$** (il combinatore spaziale)
* **$z = \text{roosterPainter}$** (il pittore variabile che arriverà in seguito a sinistra)

`​`​`typescript
const R = <U, T, V>(x: U) => (y: (arg: T) => (arg: U) => V) => (z: T): V => y(z)(x);

// 1. Fissiamo x = wavePainter e y = beside
const attachToRightOf = R(wavePainter)(beside);
// Tipo inferito: (z: Painter) => Painter

// 2. Passiamo il pittore di sinistra z = roosterPainter
const finalPicture = attachToRightOf(roosterPainter);
`​`​`

---

### Perché il Robin è così potente?

Il Robin ti permette di trasformare un **dato** ($x$) in un **costruttore di trasformazioni** ($R(x)$). 

Invece di pensare *"Prendo `beside`, gli do `rooster` e poi gli do `wave`"*, con $R$ puoi pensare direttamente dal punto di vista dell'oggetto: *"Prendo `wave`, gli aggancio il combinatore `beside`, e ottengo una funzione che aspetta solo di sapere chi mettergli a sinistra"*.
