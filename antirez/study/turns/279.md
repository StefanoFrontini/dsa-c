### Opzione 1: JavaScript / TypeScript + Canvas API (Consigliata per immediatezza)

Se vuoi focalizzarti sui **concetti funzionali** senza perdere ore a configurare librerie grafiche di sistema, **JavaScript/TypeScript è la scelta più semplice in assoluto**.

* **Zero Installazione:** Hai già tutto sul tuo Mac (browser e un editor di testo). Nessuna dipendenza C, nessun binding OpenGL o finestra X11 da configurare.
* **Supporto Nativo alle Closure:** JS possiede funzioni di prima classe e *lexical closure* native. Puoi tradurre direttamente la `lambda` di SICP in una *arrow function*:
  * In LISP: `(define (beside p1 p2) (lambda (frame) ...))`
  * In JS: `const beside = (p1, p2) => (frame) => { ... }`
* **Output Grafico Immediato:** La Canvas API 2D fornisce già primitive di linea e trasformazioni di matrice (traslazione, rotazione, scala) che mappano direttamente il concetto di `Frame`.

---

### Opzione 2: Ambiente LISP su macOS (Racket / DrRacket)

Se tenti di installare un Common Lisp classico (es. SBCL) su macOS e collegarlo a librerie grafiche come SDL2 o Cairo, incontrerai un percorso ad ostacoli complesso tra Homebrew, file `.dylib` e binding C.

Tuttavia, esiste una "scorciatoia" perfetta se vuoi la sintassi LISP pura: **DrRacket**.

* **Installazione in un click:** Scarichi l'applicazione per macOS e sei pronto.
* **Pacchetto SICP Integrato:** Racket possiede un modulo dedicato (`#lang sicp`) e una libreria grafica già pronti (`sicp-pict`). Troverai le funzioni del Picture Language (`beside`, `above`, `rotate90`, `flip-vert`) già pronte ed eseguibili direttamente dall'IDE senza configurare nulla.
