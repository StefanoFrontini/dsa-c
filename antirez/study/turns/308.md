Nel *Picture Language*, il **Mockingbird ($M x = x x$)** è la chiave di volta per realizzare l'effetto più affascinante della grafica vettoriale: **l'auto-similarità e i frattali (come `square_limit` o `corner_split`) senza usare funzioni nominate o la parola chiave `function` ricorsiva**.

Poiché il Mockingbird prende una funzione e la applica a se stessa ($M(f) = f(f)$), ti permette di **iniettare la ricorsione in un pittore anonimo**.

### 1. Creare Frattali e Disegni Ricorsivi (Self-Nesting)

Immagina di voler creare un motivo frattale in cui un'immagine viene affiancata a versioni sempre più piccole di se stessa. 

Invece di scrivere una funzione con un nome e chiamarla al suo interno, definiamo una struttura che accetta `self` (se stessa) come parametro. Il Mockingbird si occuperà di innescare il loop.

`​`​`typescript
type Painter = (frame: Pair) => void;
type SelfApplicable<R> = (x: SelfApplicable<R>) => R;

const M = <R>(x: SelfApplicable<R>): R => x(x);

// 1. Definiamo la regola del frattale: prende "self" come primo argomento
const makeFractal = (self: any) => (p: Painter) => (depth: number): Painter => {
  if (depth === 0) return p;

  // 🪄 IL TRUCCO DEL MOCKINGBIRD:
  // self(self) rigenera la funzione ricorsiva al volo!
  const smaller = self(self)(p)(depth - 1);

  // Mettiamo il pittore p a sinistra, e a destra mettiamo p sopra il livello ricorsivo
  return beside(p)(below(p)(smaller));
};

// 2. Usiamo M per "accendere" la ricorsione pura!
const fractal = M(makeFractal);

// 3. Generiamo un disegno frattale profondo 4 livelli:
const waveFractal = fractal(wavePainter)(4);
`​`​`

#### Cosa succede sotto il cofano?
Quando esegui `M(makeFractal)`:
1. $M$ calcola `makeFractal(makeFractal)`.
2. All'interno del corpo, `self` diventa `makeFractal`.
3. Quando il codice valuta `self(self)`, sta rieseguendo $M$ per il livello di profondità successivo ($depth - 1$), creando la struttura frattale ad albero senza che nessuna funzione sapesse il proprio nome!

### 2. Auto-Duplicazione Simmetrica dei Combinatori

Il Mockingbird applica un argomento a se stesso. Se hai un combinatore che accetta due parametri identici (ad esempio una funzione che affianca due istanze dello stesso pittore), puoi usare $M$ per eliminare la ridondanza.

Supponiamo di voler creare una funzione `mirror` che prende un trasformatore di pittori e lo applica due volte:

`​`​`typescript
// Una funzione che applica lo stesso trasformatore a se stesso
const duplicateTransform = (transform: any) => transform(transform);

// Con M possiamo esprimere la duplicazione di comportamento
const doubleFlip = M((f: any) => (p: Painter) => f(f(p)));

### 3. Dal Mockingbird al Combinatore $Z$ (Ricorsione Pura in TypeScript)

Il Mockingbird è il genitore di tutti i combinatori ricorsivi (come il combinatore $Y$ o $Z$). Se unisci il **Bluebird ($B$)**, il **Cardinal ($C$)** e il **Mockingbird ($M$)**, puoi costruire il **Combinatore $Z$** (la versione per linguaggi *strict/eager* come JavaScript e TypeScript):

`​`​`typescript
// Il combinatore Z (derivato matematicamente da M)
const Z = <A, B>(f: (g: (x: A) => B) => (x: A) => B) =>
  ((x: any) => f((v: A) => x(x)(v)))
  ((x: any) => f((v: A) => x(x)(v)));

// Ora puoi definire QUALSIASI algoritmo spaziale ricorsivo per il Picture Language:
const cornerSplit = Z((self) => (p: Painter) => (n: number): Painter => {
  if (n === 0) return p;
  const smaller = self(p)(n - 1);
  return beside(p)(below(smaller)(smaller));
});

// Uso:
const myCorner = cornerSplit(wavePainter)(5);
`​`​`

### In sintesi

Nel contesto del *Picture Language*:
* **$B$ (Bluebird)** ti serve per le **pipeline** (es. "ruota e poi affianca").
* **$C$ (Cardinal)** ti serve per la **geometria** (es. "scambia destra/sinistra o sopra/sotto").
* **$M$ (Mockingbird)** ti serve per la **prospettiva infinita e i frattali** (es. "metti una copia di questo quadro dentro se stesso").
